# 棚のWeb表示データ

`small.bin` は「棚小 v4.step」、`large-1050.bin` は「棚大 v3.step」を基に高さを修正したWeb用三角形メッシュです。大小で別々の形状を使用しています。元のSTEPは公開フォルダへ含めていません。

変換：occt-import-js 0.0.23（OpenCascade）。単位mm、linearDeflectionType=absolute_value、linearDeflection=0.8、angularDeflection=0.6。頂点は0.01mm単位へ丸めています。

表示座標はXが左右、Yが高さ、正面が+Z。小型は元座標を `[x-350,z+1050,175-y]`、大型は `[x+450,z+1197.508188677331,-225-y]` に変換しました。

大型は元CADの下段が150mm高かったため、上記の座標変換後に `Y <= 500` の頂点を `Y × 350 / 500`、それより上の頂点を `Y - 150` に変換しました。下段を短縮し、棚板・上部を150mm下げています。幅・奥行は維持しています。これはWebメッシュの補正で、下段のワイヤー間隔・断面にも縦方向の縮小が適用されます。元STEP自体の寸法編集ではありません。

バイナリ形式（little endian）：先頭8バイトはUint32の座標要素数・インデックス要素数。続いてFloat32のXYZ座標、Uint32の三角形インデックス。法線は表示時に計算します。

色付きの貸出面は棚本体と別の案内レイヤーです。番号の左右・種類は料金プランの図に合わせています。大小とも高さ区切りは1050/700/350/0mmで、上段・中段・下段は各350mmです。水平面は棚板に合わせ、大小とも353mm付近に配置しています。

描画ライブラリはThree.js 0.170.0を同一サイト内の `vendor/` に配置しています。ライセンスは `vendor/THREE-LICENSE.txt` を参照してください。外部CDNや実行時のSTEP変換は不要です。
